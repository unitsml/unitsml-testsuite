= unitsml-testsuite

Cross-language conformance suite for UnitsML: the frozen render and
conversion corpora replayed by every unitsml runtime (Ruby, TypeScript).

== corpora/renders

89 inputs drawn from unitsml-ruby's conv specs
(`spec/unitsml/conv/{xml,asciimath,...}_spec.rb`), frozen from
**unitsml-ruby 0.6.11**:

* `expected-renders.json` — per input: `norm_text`, `asciimath`, and the
  UnitsML `xml` document. Two rows are frozen as `ruby_error` (the
  pre-existing unitsml-ruby mml `NoMethodError` on `kcal_IT`); replays
  skip them and they must flip to `render` rows when upstream is fixed.
* XML comparison is **semantic** — entities decoded, whitespace between
  tags collapsed, attribute quoting unified — mirroring the upstream
  conv specs' `be_xml_equivalent_to` contract.

== corpora/conversions

25 conversion vectors from unitsml-ruby#92 (`Conversions` execution,
unitsml-ruby PRs #98/#99/#100), frozen from the unitsml-ruby
implementation:

* `expected-conversions.json` — five case kinds:
  ** `convert` — a `Quantity#convert_to` hop (canonical path, or through
     caller-supplied `definitions` given as UnitsML
     `Float64ConversionFrom` XML with their lookup key), expected value
     as an exact decimal string.
  ** `difference` — the same for a difference of two quantities
     (`20 degC − 15 degC → 5 K`): conversion must skip the affine
     addends.
  ** `definition` — `Conversion::Definition` execution: forward
     `y = d + (b/c)(x + a)` and inverse `x = (c/b)(y − d) − a` in exact
     rational arithmetic, the `exact` flag, and verbatim lexical decimal
     preservation.
  ** `resolve` — `initialUnit` resolution: document-local fragments
     before the register, register fragments, and reference URIs.
  ** `error` — typed refusals: affine definitions at power ≠ 1,
     definition-vs-canonical disagreement, unresolvable `initialUnit`,
     and `SpecialConversionFrom`/`WSDLConversionFrom`.
* All numeric values are exact decimal strings; replays parse them as
  Rationals and compare exactly.

== Replay contract

A conforming runtime parses each input (`Unitsml.parse` semantics, the
`unitsml(...)` wrapper and extras included) and asserts:

* `norm_text` equality,
* AsciiMath render equality,
* semantic XML equality of the UnitsML document.

`unitsml-ruby` replays via `CORPUS_DIR=… bundle exec rspec
spec/unitsml/render_corpus_spec.rb`; `unitsml-ts` via
`CORPUS_DIR=… npm run replay`. Both CI pipelines check this repository
out and enforce it.

The conversion corpus replays as `CONVERSION_CORPUS_DIR=… bundle exec
rspec spec/unitsml/conversion_corpus_spec.rb` (unitsml-ruby) and
`CONVERSION_CORPUS_DIR=… npm run replay:conversions` (unitsml-ts), the
same checkouts enforced by CI.
